# Brief 20 · Parameter-efficient finetuning (LoRA, QLoRA)

- File: `pages/20-peft-lora.html` · Part IV · Post-training · P1 · ~40 min · body 4,000–5,500 words
- Prereqs: 04, 19. Drill module name: `lora`

## Purpose
LoRA is everywhere in practice and in interviews ("implement a LoRA layer", "why initialize B to
zero?", "what rank?"). Cover the math, QLoRA's quantization tricks, and the evidence about what
low-rank updates can and cannot learn, including for RL.

## Must cover
1. **Motivation**: full finetuning memory (weights + grads + Adam states; link 15) vs adapters;
   the intrinsic-dimension argument (Aghajanyan et al.). Chinese: 参数高效微调, 低秩适配.
2. **LoRA**: \(W' = W + \frac{\alpha}{r} BA\) with \(A \in \R^{r \times k}\), \(B \in \R^{d \times r}\);
   init (A Gaussian/Kaiming, B = 0, so the model starts unchanged); the α/r scaling and why it
   decouples LR from rank (and rsLoRA's \(\alpha/\sqrt{r}\) argument; verify); which modules to
   adapt (attention only vs all linear layers; evidence); merging for zero inference overhead;
   parameter and memory savings with a worked example.
3. **QLoRA**: 4-bit NormalFloat (NF4) quantization of the frozen base (quantiles of a normal,
   blockwise absmax scaling with block size 64), double quantization of the scales, paged
   optimizers; compute in bf16 after dequantization; memory math for a 65B model on one 48GB
   GPU (verify the paper's claim).
4. **Variants**: DoRA (magnitude/direction decomposition), LoRA+ (different LRs for A and B),
   adapters (Houlsby), prefix and prompt tuning (why they fell out of favor), IA³ briefly.
5. **What LoRA can't do**: "LoRA learns less and forgets less" (Biderman et al. 2024): lower
   capacity on continued pretraining/code/math vs full FT but better retention; rank needed
   grows with the amount of new information. Thinking Machines' "LoRA Without Regret" (2025
   blog; verify claims): LoRA matches full FT for RL and small SFT when applied to all layers,
   because RL provides few bits per episode. Present evidence and caveats.
6. **Serving many adapters** (S-LoRA, Punica: batched adapter kernels) briefly.

- What does α/r do? What happens if you change r but not α?
