# Brief 22 · RL foundations for LLMs: policy gradient to PPO

- File: `pages/22-rl-foundations.html` · Part V · Reinforcement learning · P0 · ~70 min · body 6,000–8,000 words
- Prereqs: 01, 06, 21. Drill module name: `pg`

## Purpose
The minimum RL theory an LLM researcher must derive fluently: the token-level MDP, the policy
gradient, baselines and advantages, GAE, importance sampling and PPO, and KL estimators. The
reader knows ML but maybe not RL; build it rigorously and always map each concept to LLM
generation.

## Must cover
1. **LLM generation as an MDP**: state = prompt + prefix, action = next token, deterministic
   transitions, reward usually only at the end (sparse), episode = one response; bandit view
   (whole response as one action) vs token-level view; discount γ = 1 in practice. Chinese:
   强化学习, 策略梯度, 优势函数, 近端策略优化, 重要性采样.
2. **Policy gradient theorem** via the log-derivative trick, written for sequences:
   \(\nabla_\theta J = \E[\sum_t \nabla\log\pi(a_t|s_t)\, G_t]\); causality (reward-to-go).
3. **REINFORCE and baselines**: variance; proof that a state-dependent baseline is unbiased;
   the value function as the optimal-ish baseline; advantage \(A = Q - V\).
4. **Actor-critic and GAE**: TD error \(\delta_t\); GAE\((\gamma, \lambda)\) as an exponentially
   weighted sum; the bias–variance knob; how it behaves with a terminal-only reward and γ = λ = 1.
5. **Off-policy correction**: importance ratio \(\rho_t = \pi_\theta/\pi_{old}\); why multiple
   minibatch epochs make data slightly off-policy.
6. **TRPO → PPO**: trust regions; PPO-clip objective \(\min(\rho A, \clip(\rho, 1\pm\epsilon)A)\)
   and exactly what the clip does for positive vs negative advantages (draw the four cases);
   value loss (and value clipping), entropy bonus; typical ε = 0.2.
7. **KL control**: KL penalty in the reward (per-token, InstructGPT style) vs KL in the loss
   (GRPO style); **KL estimators** k1 = \(\log(q/p)\) ... use the exact definitions from
   Schulman's note (k1 = −log r, k2 = ½(log r)², k3 = (r − 1) − log r with r = p/q; verify
   notation and which distribution samples come from), their bias and variance, and why k3 is
   popular (unbiased and nonnegative).
8. **Token vs sequence level**: where the ratio and the loss are aggregated (preview of the
   GRPO/GSPO/Dr. GRPO debates on page 24).
9. **Practicalities**: advantage normalization/whitening, reward scaling, value-head init,
   the four-model memory footprint (preview 23).

## Required interview questions (14–16; include these)
- Derive the policy gradient. Why does subtracting a baseline not bias it?
- What is the advantage function and how does GAE estimate it?
- Explain PPO's clipped objective. What happens for positive and negative advantages?
- Why is a KL penalty to the reference model used in RLHF?
- Compare the k1, k2, k3 KL estimators.
- Why is RL on LLMs usually "bandit-like", and what does that imply for credit assignment?
- On-policy vs off-policy: where does PPO sit, and why does that matter for sample reuse?
