## Must cover (verify all numbers)

   and a simple template; AIME pass@1 trajectory (15.6% → 71.0%, 86.7% with majority voting;
   verify), response-length growth, the "aha moment", readability and language-mixing issues.
   Chinese: 冷启动, 拒绝采样, 蒸馏.
2. **R1**: cold-start long-CoT data (thousands of examples), reasoning RL with a language
   consistency reward, rejection-sampling SFT (~600K reasoning + ~200K non-reasoning), final RL
   for all scenarios (rule-based rewards for reasoning, RMs for general); results vs o1; the
   distilled Qwen/Llama models and the "distillation beats RL at small scale" finding; negative
   results (PRM, MCTS). The Nature version (2025) and any additional disclosures it made (e.g.
   RL training cost or safety details; verify before stating).
3. **R1 updates** (e.g. R1-0528; verify what changed and reported results).
4. **V3.1** (Aug 2025) and **V3.1-Terminus**: hybrid thinking/non-thinking in one model via the
   chat template, improved tool use/agents, long-context extension data amounts, FP8 scale
   format changes (UE8M0) if documented (verify every claim from the model card/release notes).
5. **V3.2-Exp and V3.2** (verified in 2512.02556): DeepSeek Sparse Attention (lightning indexer:
   \(I_{t,s} = \sum_j w_{t,j} \operatorname{ReLU}(q_{t,j} \cdot k_s)\), FP8, few heads; top-2048
   selection; built on MLA's MQA mode; dense warm-up of the indexer with a KL loss to the summed
   attention distribution, then sparse training, with token counts), inference cost curves,
   parity evaluations; post-training: specialist distillation, mixed RL in one GRPO stage,
   rule-based + length penalty + language consistency rewards, rubric-based generative RM, RL

   thinking with tools and context management; V3.2-Speciale (IMO/IOI/ICPC gold) and its token
   inefficiency; stated limitations (knowledge breadth, token efficiency).

## Drill: `exercises/drills/dsa.py`
- `lightning_index_scores(q_idx, w_idx, k_idx)` (ReLU-weighted multi-head scores, causal).
- `dsa_attention(q_lat, q_rope, c_cache, kr_cache, scores, k_top)`: select top-k per query and
  run MQA-mode attention over the selected latents only.
- `indexer_kl_loss(attn_probs_per_head, index_scores, selected=None)`: L1-normalized summed
  attention as the target, KL to softmax of index scores (dense and sparse variants).
- Tests: with k_top ≥ sequence length, DSA equals dense MQA-mode attention; selection respects
  causality; KL is zero when the index softmax equals the target.
