## Purpose
Llama defined the "standard recipe" of open dense LLMs, and the Llama 3 paper is the most
detailed public account of training a frontier dense model (405B). Llama 4's move to MoE and its
reception are instructive. Cover what changed each generation and why.

## Must cover (verify every number)
1. **Llama 1** (Feb 2023): pre-norm RMSNorm, SwiGLU, RoPE, no biases; public data only; 1T–1.4T
   tokens; "smaller models trained longer" motivated by inference cost (link 13); LLaMA-13B vs
   GPT-3 claim.
2. **Llama 2** (Jul 2023): 2T tokens, 4K context, GQA for 34B/70B (verified: Table 1, App.
   A.2.1), RLHF details (two RMs, rejection sampling + PPO, Ghost Attention), Code Llama's RoPE
   base 1e6 for long context.
3. **Llama 3 / 3.1** (2024): 128K tiktoken-based vocabulary (compression gains), 8K → 128K
   context (RoPE base 500,000; 3.1's rope scaling), ~15T tokens, GQA with 8 KV heads at all
   sizes, 405B dense config (layers, width, heads; verify Table 3); data mix proportions and
   annealing; scaling-law methodology for downstream prediction; infrastructure (16K H100s, 4D
   parallelism, MFU, the reliability numbers: interruptions and causes; verify); post-training
   (SFT + rejection sampling + DPO over several rounds; no PPO) and why; long-context stages.
4. **Llama 4** (Apr 2025; model card/blog, verify each claim): MoE (Scout: 17B active / 109B
   total, 16 experts; Maverick: 17B active / 400B total, 128 experts; Behemoth teacher), shared
   expert and alternating dense/MoE layers (verify), early-fusion multimodality, iRoPE
   (interleaved RoPE and NoPE attention layers, inference-time attention temperature scaling) and
   the 10M-context claim for Scout, MetaP hyperparameter method, FP8 training; reception issues
   (e.g. an experimental chat variant on LMArena; describe neutrally from sources).
5. **The Llama recipe as a baseline**: a table of what stayed constant and what changed across
   generations, and which choices other labs adopted.
