# Brief 33 · Architecture atlas

- File: `pages/33-architecture-atlas.html` · Part VI · Case studies · P0 · ~35 min · body 3,000–4,500 words plus tables
- Prereqs: 26–32. Drill module name: `config_zoo`

## Purpose
One reference page to compare every major open model's configuration side by side, and to read
off what the field converged on and where it still disagrees. Interviewers expect you to know
typical numbers (head dims, KV heads, expert counts, vocab sizes, RoPE bases).

## Must cover
1. **The master table** (~20 models): release date; total / active params; layers; d_model;
   attention type (MHA/GQA/MLA/hybrid/sparse) with heads / KV heads / head dim; FFN type and
   hidden size; MoE (routed / active / shared, expert hidden size); vocab; context; positional
   scheme and RoPE base; norm and stability tricks (QK-norm, soft-cap, sinks); training tokens.
   Models: GPT-3 175B, Llama 2 70B, Llama 3 8B/70B/405B, Llama 4 Maverick, Mistral 7B, Mixtral
   8x22B, Gemma 2 27B, Gemma 3 27B, Qwen2.5-72B, Qwen3-32B, Qwen3-235B-A22B, Qwen3-Next-80B,
   DeepSeek-V2, DeepSeek-V3/V3.2, Kimi K2, GLM-4.5, MiniMax-M1 or M2, gpt-oss-120b, OLMo 2 32B,
   plus any major 2026 release. **Every cell must come from a config.json, model card or paper**;
   put "n/a" or "?" rather than guessing; list sources per row.
2. **Derived columns** computed with the drill: KV bytes per token (bf16), FLOPs per token
   (2 × active params + attention at 8K), params per token trained.
3. **Convergence analysis**: what almost everyone now does (pre-norm RMSNorm, SwiGLU, RoPE, no
   biases, GQA or MLA, large vocab, MoE at the frontier, QK-norm spreading) and why (link each
   to its page); where designs still diverge (attention family, MoE granularity and shared
   experts, balancing method, optimizer, local:global ratios).
4. **Timeline figure** 2020–2026 with key architectural introductions.
5. **"Rules of thumb" box**: head dim 128 (or 64/256 exceptions), KV heads 8, d_ff/d ratios,
   experts/active ratios, tokens/param trends.
