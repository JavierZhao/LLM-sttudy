# Brief 35 · Coding drills

- File: `pages/35-coding-drills.html` · Part VII · Interview toolkit · P0 · ~90 min · body 3,000–5,000 words plus code
- Prereqs: all drills so far. Drill module names: `layernorm_backward`, `beam_search`

## Purpose
The practice hub for coding rounds: an index of every drill in the course ranked by how often
such questions appear in LLM interviews, with time targets and "what the interviewer checks";
plus a few classic whiteboard problems not covered elsewhere, with full solutions on the page.

## Must cover
1. **How LLM coding rounds work**: typical formats (implement a component in PyTorch/NumPy,
   debug a broken training loop, optimize a slow function), what interviewers look for (shapes,
   masking, numerical stability, tests, complexity), and a practice protocol (timebox, no
   references, then run tests, then compare with the solution).
2. **The drill index**: a table of all drills in `exercises/` (read `exercises/README.md` and the
   drill files), grouped into tiers: must be fluent (attention with causal mask, KV-cache decode,
   RoPE, sampling, cross-entropy/log-softmax, BPE, LoRA, DPO loss, GRPO advantages), should be
   comfortable (MoE router/layer, GQA, RMSNorm/SwiGLU block, flash-style online softmax,
   speculative acceptance), stretch (MLA absorbed decode, DSA, FP8 tiling, linear attention
   recurrence). Each row: page link, file, target minutes, key pitfalls.
3. **New classic problems** with full solutions on the page and as drills:
   - LayerNorm/RMSNorm backward pass by hand (derive the gradient; implement; compare to autograd).
   - Beam search with length normalization over a provided step function.
   - A "debug this training loop" exercise: a short buggy PyTorch LM training loop with 5–6
     planted bugs (missing zero_grad, wrong label shift, mask applied after softmax, wrong
     reduction, eval mode not set, gradient clipping order) and the fixed version with
     explanations (on the page only).
4. **Common mistakes checklist** (shapes, dtype/upcasting, mask polarity, −inf NaNs, off-by-one
   in label shift, in-place ops breaking autograd, forgetting causal mask in decode chunk).

## Required interview questions
8–10 `details.qa` items of the form "what bug does this snippet have?" or "what would you test?".

## Drills
- `exercises/drills/layernorm_backward.py`: `layernorm_forward(x, g, b, eps)` returning cache,
  `layernorm_backward(dy, cache)` returning dx, dg, db; same for RMSNorm. Tests vs autograd with
  `gradcheck`-style comparisons in float64.
- `exercises/drills/beam_search.py`: `beam_search(step_logprobs_fn, bos, eos, beam, max_len,
  length_penalty)`; tests on a toy step function with a known best sequence.

## Primary sources
- The course's own drills; Holtzman et al. 2019 for beam search behavior; Wu et al. 2016 (GNMT) for length penalty (verify formula)
